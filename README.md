- Sprint 3 status and release gate: [`docs/SPRINT_3_REPORT.md`](docs/SPRINT_3_REPORT.md), [`docs/PRODUCTION_RELEASE_CHECKLIST.md`](docs/PRODUCTION_RELEASE_CHECKLIST.md), [`docs/OWNER_APPROVAL_REGISTER.md`](docs/OWNER_APPROVAL_REGISTER.md).

- [`docs/`](docs/README.md): strategy, brand, website, SEO and technical documentation. Start at `docs/README.md`.
- [`brand/`](brand/SOURCES.md): brand source files and asset package. Start at `brand/SOURCES.md`.
