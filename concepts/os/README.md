# Option D, «Tamm OS» (owner 2026-11-26: «a fourth option, completely different, crazy but stable»)

The agency as an operating system. A short start-up (symbol + purple load bar), then a desktop on obsidian with the 45° blade
as wallpaper and «قول. تم.» in outline. Every section is an app: About (approved headline, facts, why we started, mission, vision),
Services (two panes, the nine services by discipline), Showreel («قولها… تمّت» with sound), Studio (the nine films), Numbers
(the three approved cases as a sheet; a row opens how it was measured, verbatim), Clients (the home page's direct-client logos),
Start a project (a mail composer that writes the message for the visitor to copy) and Read me (preview note, track-record line, markets).
Windows drag, stack, minimise and close (Esc closes the front one); the dock keeps the main apps; Tamm sits in the corner with
rotating tips and opens the composer. On phones it becomes a home screen and apps open as full-screen sheets with a back arrow.
Arabic first with an English switch, one dark look, IBM Plex Sans Arabic only. No libraries; separate from the Astro site.

Publish like `concepts/chat` (same `data.json` at `__DATA__`, same `media/` folder).
