# saytamm-brand-creative-studio

Claude-compatible skill package.

## Contents
- `SKILL.md`: skill definition and operating workflow.
- `references/SAYTAMM_CONTEXT.md`: approved SayTamm identity, project facts and safeguards.
- `templates/`: reusable intake brief.

## Installation
Upload this folder as a ZIP through Claude's Skills interface (Customize → Skills → Upload a skill), or install the folder in a supported local Claude skills directory. Keep the folder name and `SKILL.md` filename intact.

## Use in ChatGPT
This ZIP is a portable instruction package, not an automatically installed ChatGPT skill. In ChatGPT, attach the ZIP or its extracted `SKILL.md` and reference file to a dedicated Project, add the skill's operating rules to Project Instructions, and invoke the role by its shortcut or name. Actual file creation, web research and code execution depend on the tools available in that chat.

## Important
This skill does not independently create real customer research, verify claims without sources, or publish/deploy anything. Follow the evidence and approval safeguards in `SKILL.md`.
