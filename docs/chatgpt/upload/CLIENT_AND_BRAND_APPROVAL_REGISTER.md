## Status definitions

- **Relationship:** *Owner-confirmed* = the owner stated it in this project (date given). No contract or client letter is on file for any brand.
- **Display permission:** *Owner-asserted* = the owner stated SayTamm may show it. **Written client permission is not on file for any brand** — that is an external permission this project cannot create. It is recorded as a pre-launch check, not as a blocker to staging.
- **Asset source:** where the logo or work file came from.
