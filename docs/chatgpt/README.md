# SayTamm — ChatGPT Project pack

## Setup (5 minutes)

1. In ChatGPT: **Projects → New project** → name it "SayTamm".
2. **Instructions:** open the project settings and paste the full contents of `1_PROJECT_INSTRUCTIONS.md` (about 3,800 characters).
3. **Files:** unzip `SayTamm_ChatGPT_Project.zip` and upload all 28 files from `upload/`.
4. First message to test it: «لخّص لي مشروع قول تم في 10 نقاط، وإيه اللي ناقص قبل الإطلاق؟»

## Keep it current

When something changes (a new client, an approved figure, the legal review), update `2_SAYTAMM_PROJECT_KNOWLEDGE.md` and re-upload it, so ChatGPT never works from an old version. These files are internal: they include unpublished figures and open legal questions.
