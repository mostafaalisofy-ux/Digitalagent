## Attribution framework [RECOMMENDATION — mandatory once approved]

Every piece of work gets exactly one category. The category controls where and how it can appear.

| Category | Definition | Where it can appear | How it is labelled |
|---|---|---|---|
| **A. SayTamm work** | Executed under SayTamm, by the SayTamm team | Work section, case studies, proof numbers, ads | "SayTamm case study" |
| **B. Approved SayTamm case study** | Category A **plus** written client approval to publish name, visuals and figures | Everywhere, including named results on the homepage | Client name + results |
| **C. Leadership & team experience** | Work done by SayTamm's founders or team at previous companies (e.g. Steps Agency) | About page ("Experience"), founder bios, proposals, **never the Work grid** | "Work led by our team at [previous agency]" or "Team experience"; previous agency named where agreements require it |
| **D. Historical / reference only** | Work we cannot attribute cleanly, or with no permission | Internal only | Not published |

**Hard rules**
1. Category C work is **never** presented as SayTamm work, never placed in the Work index, and never counted in SayTamm proof numbers.
2. Client logos are shown only with permission. A "brands our team has worked with" logo wall is Category C and must be labelled as such.
3. No metric without: source, period, baseline, what it measured, and who approved publication. Otherwise it is marked `[[NEEDS APPROVAL]]` and does not ship.
4. Steps Agency's rights: confirm that the owner has the right to show work produced at Steps Agency (contract, NDA, IP ownership). **OQ-11.**
5. Original campaign visuals are used wherever possible. They are never replaced with stock.

## Case study template [APPROVED structure — SOURCE: brief]

Each case study is one content file (EN + AR) with this structure. Sections marked ★ are required to publish.

```yaml
slug:
category: A | B | C          # see framework; C cannot be published as a case study
client:                       # ★ name, or anonymised descriptor ("Saudi real estate developer") if not approved
industry:                     # ★
market:                       # KSA / GCC / other
period:                       # ★ e.g. 2026-Q1 → 2026-Q3
services: [strategy, media, performance, data]
approval:
  client_publication: yes|no|pending   # ★ must be "yes" for named Category B
  approved_by:                 # name / role / date
  metrics_source:              # platform / CRM / analytics + date exported
```

1. **Client / Brand** ★
2. **Industry** ★
3. **Business challenge** ★ — the commercial problem, not the marketing task.
4. **Strategic objective** ★ — the number that mattered.
5. **Strategic approach** — what we decided, and why.
6. **Execution** — channels, creative, testing, tracking.
7. **Performance results** ★ — metrics with baseline and period, each one sourced.
8. **Business impact** — what the results meant for the business.
9. **Key learning** — what we would tell the next client.

Reading pattern on the page: **Headline KPI → insight → action** (the Bible's report rule), with campaign visuals throughout.
