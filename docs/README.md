# SayTamm — Project Knowledge Base

The permanent record of what SayTamm is, what has been decided, and what is still open.
Read this before changing brand, business, or website direction. Update it whenever a decision is made.

## Labels used in every document

| Label | Meaning |
|---|---|
| **[CONFIRMED]** | Verified directly from a file, measurement, or the owner |
| **[APPROVED]** | A brand decision stated as approved in the authoritative sources (see `/brand/SOURCES.md`) |
| **[SOURCE]** | Taken from a source document, with the document named. Not independently verified |
| **[RECOMMENDATION]** | Our strategic proposal. **Needs owner approval before it is treated as decided** |
| **[ASSUMPTION]** | A working assumption used to keep moving. Must be validated |
| **[MISSING]** | Information we need and do not have. Tracked in `OPEN_QUESTIONS.md` |

An unlabeled statement inherits the label of its section heading.
