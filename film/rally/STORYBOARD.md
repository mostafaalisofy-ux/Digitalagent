# «The Rally» — 20 s, 1080×1080, English, 120 BPM (beat = 0.5 s)

**Research (from the repo's approved sources):** SayTamm is a digital marketing & performance agency (founded 2021, a team of 30):
strategy, creative, media and technology in one team, judged against one business number. Brand: Obsidian/Soft White with
Electric Purple as the only accent; Satoshi for English; the symbol is a T with a separate 45° blade. SayTamm has no software
product, so the "interface" is the everyday client–agency workflow (a request message, a comment pin on a design, version steps,
an Approve button, a performance chart), rebuilt as vector layers in the brand style. No figures, no client names, no tools named.

**Reference (owner's video):** a top-down tennis court, bold kinetic type, counters, an end card.
**Idea:** the client–agency back-and-forth is a rally. The client sends the ball, the SayTamm team returns it, done, every time.

**Through-line object: the purple ball.** Full stop → request badge → comment pin → "next version" button → Approve button →
data point → the blade of the SayTamm symbol (from the original file) on the end card.
